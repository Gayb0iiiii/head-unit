# Headunit design
A landscape touch-first launcher, with a narrow persistent left dock and large familiar rounded app tiles. Opaque dark-blue glass keeps text readable over user-selectable scenery. This is intentionally CarPlay-like rather than a web dashboard. No vehicle branding. Diagnostics belongs inside Settings.

Palette: ink #101d30, glass #25394f, cloud #f3f7fc, lagoon #57b7cd, horizon #e8ad83, focus #a9dfff. System sans typography, 16–18px body, 28–36px titles. App glyphs are original inline SVG, not Apple assets. 64px minimum dock targets; quiet motion and visible keyboard focus. Native projection remains owned by LIVI; the preview does not counterfeit a live stream.
